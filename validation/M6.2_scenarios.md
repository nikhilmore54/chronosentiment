## Calibration Findings

Two calibration findings emerged during M6.2 execution. Both are correct behaviour, not bugs.

### Finding 1 — DisruptionRecovery re-assigns orphaned pairings by default

`DisruptionRecovery::recover()` attempts to re-assign orphaned pairings to existing rotations in Phase 2. Without a constraining `LegalityChecker` rule, the orphaned pairing is re-assigned back to the same rotation, leaving total pairing count unchanged.

**Resolution:** SCN-007 registers `MaxOnePairingPerRotation` to block re-assignment. This validates the architectural separation:

```
Recovery
    │
    ▼
LegalityChecker (oracle)
    │
    ▼
Accept / Reject recovery move
```

Recovery is policy-neutral; legality encapsulates operational constraints. This is correct Ports & Adapters design.

### Finding 2 — RobustnessEvaluator requires target capacity, not minimum capacity

`RobustnessEvaluator::new(_, _, max_pairings_per_rotation, _)` must be set to the **operational target capacity** (e.g. 2) rather than the minimum (1). With `max=1`, every rotation is at 100% capacity regardless of actual load, producing identical scores for all rosters.

**Resolution:** SCN-009 uses `max_pairings_per_rotation=2`, giving the generous roster (1/2 = 50% slack) a higher score than the dense roster (2/2 = 0% slack).

**Calibration rule:** `max_pairings_per_rotation` represents the design capacity of a rotation, not the minimum viable load.

## Pairing Invariant (Design Record)

The correct Layer 1 pairing invariant is:

```
first_departure_airport == crew_base
last_arrival_airport    == crew_base
```

Intermediate routing is unconstrained. Valid pairings include:

```
LHR → CDG → LHR                    (2 legs)
LHR → CDG → FRA → LHR              (3 legs)
LHR → AMS → FRA → MAD → LHR        (4 legs)
LHR → JFK → BOS → ORD → LHR        (4 legs, transatlantic)
```

Future extensions (deferred to SCN-012+):
- `CrewBasePolicy` for airport systems (LHR/LGW/LCY treated as equivalent base)
- Deadhead activities as first-class domain objects
- Ground transfer positioning
