# Repository Governance Rules

- **RP-600 Governance Pre-Check:** Every pull request or task that creates a new top-level concept (architecture, contract, research series, executable tool, or application) must first demonstrate that an equivalent concept does not already exist in the repository. Before suggesting any new document, code, tooling, or architectural concept, always check if a similar asset exists in the codebase and prefer extending it over creating a new one.
