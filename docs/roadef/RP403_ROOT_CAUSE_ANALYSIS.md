## 2. setA-12 Investigation — Path Audit

**Research question:** Why did RP-401C produce a finite solution (26.12) while RP-401D and RP-402 both regress to inf?

### 2.1 Instance characteristics

| Field | Value |
|-------|-------|
| Nodes | 200 |
| Links | 898 |
| Demands | 400 |
| Budget | 13 |
| RP-401C result | 26.1166 (finite) |
| RP-401D result | inf |
| RP-402 result | inf |

### 2.2 Hypothesis

The regression from RP-401C to RP-401D suggests that oracle-guided candidate selection (K=5 shortest paths) makes different tie-breaking decisions than the ECMP-aware greedy used in RP-401C. For setA-12's topology, the RP-401C assignment happens to be feasible while RP-401D's oracle selection is not.

RP-402 inherits RP-401C's shared-path construction as its base, then applies budget-aware adaptation. If the base construction is already infeasible (as it appears to be for setA-12 under RP-402's construction), adaptation cannot recover it.

## 4. setA-08 Investigation — Regression Analysis

**Research question:** Why did RP-402 regress setA-08 from 48.67 (RP-401D) to inf?

### 4.1 Instance characteristics

| Field | Value |
|-------|-------|
| Nodes | 150 |
| Links | 654 |
| Demands | 200 |
| Budget | 13 |
| RP-401C result | inf |
| RP-401D result | 48.6693 (finite) |
| RP-402 result | inf |

### 4.2 Hypothesis

RP-401D uses K=5 oracle-selected paths and processes demands independently for t=0 and t=1. RP-402 uses a shared-path construction (same waypoints for both slots) as its base. For setA-08's topology, the RP-401D t=1 assignment happens to be feasible, but RP-402's shared-path base is not — and the budget-aware adaptation cannot recover it because the base construction already places demands on congested paths.

### 4.3 Investigation method

- Compare RP-401D path assignments for setA-08 vs RP-402 path assignments
- Identify which demands differ between the two solvers
- Determine whether the RP-401D feasible assignment is reachable from RP-402's base construction within budget=13
- Determine whether RP-403 could preserve the RP-401D assignment while also improving on the remaining instances
