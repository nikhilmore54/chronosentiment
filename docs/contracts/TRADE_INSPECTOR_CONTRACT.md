# Trade Inspector View Model Contract (v1.0)

## Overview
This contract defines the authoritative data structure that the `TradeInspector` UI component will consume. It is constructed from the certified artifacts generated by the backend `trace_compiler`.

## Root Interface

```typescript
export interface TradeInspectorViewModel {
  trade_id: string;
  strategy: string;
  signal: DecisionLayer;
  baseline: TradeLeg;
  perturbed: TradeLeg;
  delta: ExecutionDeltaLayer;
  explanations: ExplanationRule[];
  timeline_refs: TimelineReferences;
}
```

## Layers

### Decision Layer
Defines why the strategy wanted to trade.

```typescript
export interface DecisionLayer {
  signal_timestamp: string | number;
  signal_type: string;
}
```

### Trade Leg (Baseline / Perturbed)
Captures execution outcomes for a given leg.

```typescript
export interface TradeLeg {
  signal_time: string | number;
  fill_time: string | number;
  fill_price: number;
}
```

### Execution Delta Layer (Outcome)
Defines operational changes.

```typescript
export interface ExecutionDeltaLayer {
  delay_ms: number;
  delay_ticks: number;
  slippage_bps: number;
  missed_fill: boolean;
  diverged: boolean;
}
```

### Explanation Layer
Maps back to deterministic execution rules.

```typescript
export interface ExplanationRule {
  rule_id: string;
  severity: "info" | "warning" | "critical";
  message: string;
}
```

### Timeline References
Synchronized index mapping to the Timeline View (Milestone 3).

```typescript
export interface TimelineReferences {
  market_tick_index: number;
  signal_index: number;
  execution_index: number;
  portfolio_index: number;
}
```
