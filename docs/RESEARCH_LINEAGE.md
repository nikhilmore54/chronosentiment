## Core rule

```text
documented ≠ operational authority
```

Research code may exist, run, and inform exploration. It does **not** define replay meaning, strategy identity, GA fitness, chronology law, or certification semantics unless explicitly ratified in `AUTHORITY_MAP.md`.

```text

```

Research scripts sit **outside** this chain unless explicitly promoted through governance (ratification + map update).

## Consumer vs duplicate vs observational

| Class | May do | Must not |
|-------|--------|----------|
| **downstream consumer** | read outputs, experiment on derived metrics | redefine CRITICAL semantics |
| **semantic duplicate** | reimplement formulas locally for research | silently become canonical |
| **observational consumer** | export, plot, verify read-only | mutate replay-bearing bytes |
| **detached archive** | preserve history | compile into operational tree |
| **orphaned lineage** | reference old paths in docs/comments | imply restored authority |
