## Philosophy

Observe → Hypothesize → Experiment → Measure → Diagnose → Improve.

**Every failure must teach something that changes the next experiment.**  
Threshold rattling until success is out of process.

## Stages

| Stage | Meaning | Required output |
| --- | --- | --- |
| **TRY** | One bounded hypothesis · sealed package | Experiment ID in ELR |
| **FAIL** | Honest closed W/L + payoff + net | Recorded result |
| **OBSERVE** | Event-level failure categories | Root-cause evidence |
| **FIX** | Address demonstrated cause only | Revised hypothesis |
| **REPEAT** | New sealed package (never mutate armed soak) | Independent evidence |

Success modes: positive · negative · diagnostic discovery.
