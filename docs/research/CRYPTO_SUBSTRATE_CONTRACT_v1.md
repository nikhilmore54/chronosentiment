# CRYPTO SUBSTRATE CONTRACT v1

## 1. Constitutional Authority
This contract governs the introduction and handling of cryptocurrency market data within the ChronoSentiment Execution Laboratory. Crypto is introduced explicitly and exclusively to study **continuous topology deformation** and **long-horizon memory ecology** across uninterrupted 24/7 sessions. It is NOT introduced to exploit microstructure alpha.

## 2. Forbidden Microstructure Mythology
The following analytical framing and data utilization patterns are permanently outlawed under this contract:
1. **Exchange Alpha Prediction**: Using cross-venue latency or fragmentation (e.g., Binance vs Coinbase lag) as a predictive signal.
2. **Order Book Intelligence**: Extracting alpha from maker-taker dynamics, liquidation cascades, or funding rate predictions. 
3. **Multi-Venue Arbitrage**: Attempting to model or simulate cross-exchange execution arbitrage.
4. **Latency Exploitation**: Treating network propagation differences between centralized and decentralized nodes as exploitable edges rather than environmental topology.

## 3. Substrate Sovereignty
To preserve causal isolation, the Crypto Substrate must adhere to the following rules:
- **Single Source of Truth**: Only ONE exchange venue (e.g., Binance) may serve as the canonical baseline for any single replay hash.
- **Continuous Semantics**: The substrate will contain no synthetic session boundaries. A 72-hour dataset represents 72 hours of unbroken chronological memory flow.
- **OHLCV Restriction**: The substrate is strictly restricted to OHLCV (Open, High, Low, Close, Volume) data at a 1-minute (or explicitly defined) resolution. Granular order book snapshots (L2/L3) are prohibited to prevent microstructure drift.

## 4. Primary Research Mandate
The Crypto Substrate exists solely to expose long-memory systems to uninterrupted topological stress. It allows the laboratory to map:
- 24-hour rolling window fractures
- 1000-tick memory scars
- Persistent divergence basins
- Continuous recovery hysteresis without the artificial crutch of exchange overnight resets.

Any attempt to drift the Crypto Substrate into an adaptive microstructure optimization engine is a direct violation of `TOPOLOGY_NEUTRALITY_CONTRACT_v1` and this contract.
