# PERSISTENCE SEMANTICS CONTRACT v1

## 1. Constitutional Authority
This contract governs the vocabulary and interpretative framing used when analyzing continuous-state memory ecology. As ChronoSentiment scales to evaluate uninterrupted, multi-day topologies, the anthropomorphization of physical memory structures poses a critical risk to causal isolation. This contract exists to eliminate "Causal Mythology" before it can evolve into adaptive execution drift.

## 2. Mandatory Semantic Replacement
To prevent the mutation of observational science into algorithmic optimization, the following semantic shifts are permanently enforced across all documentation, UI layers, and codebase logic:

| Forbidden Anthropomorphism | Mandatory Physical Framing |
| :--- | :--- |
| Trapped state | Persistent divergence interval |
| Memory scar | Sustained coherence deficit |
| Healing / Recovering | Coherence convergence |
| Memory corruption | Chronology discontinuity propagation |
| Trapped basin | Non-convergent recovery region |
| Memory thermodynamics | Continuity persistence topology |

## 3. The Prohibition of "Healing" Logic
The observation of a **non-convergent recovery region** (e.g., `recovery_half_life_ticks = -1.0`) is a physical property of the memory window's interaction with the continuous execution topology. It must NEVER be treated as a "bug" to be fixed, nor a "scar" to be explicitly "healed."

Under no circumstances may the discovery of sustained coherence deficits be used to justify:
1. Adaptive memory truncation
2. Topology-aware state resets
3. "Recovery-aware" signal generation

Any code or logic that attempts to repair, rather than strictly observe, the convergence geometry of a continuous state violates both this contract and the `TOPOLOGY_NEUTRALITY_CONTRACT_v1`.
