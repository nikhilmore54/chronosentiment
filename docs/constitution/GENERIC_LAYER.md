# Generic Layer

## Purpose
This document defines the semantic neutrality of the foundational substrate. The Generic Layer represents the mechanical architecture that supports ChronoSentiment without asserting authority over domain meaning.

## Structural Responsibilities

| Layer       | Authorized Function          |
| ----------- | ---------------------------- |
| Core        | Preserves causal history     |
| Observatory | Certifies replay equivalence |

## Forbidden Authority
The Generic Layer is constitutionally forbidden from holding authority over domain semantics. Specifically, the Generic Layer must never:
- **Define "Truth"**: The layer records events exactly as they occur. It must not adjudicate which event is "correct" in the abstract, philosophical, or economic sense.
- **Infer "Market Understanding"**: It must not adapt its routing, ingestion, or parsing behavior based on inferred external market conditions.
- **Execute "Economic Interpretation"**: It must not score, weigh, or prioritize events based on their perceived domain value.

## Invariant
**The Generic Layer is a mechanically testable substrate. It preserves causality and equivalence, explicitly deferring semantic realization to higher-level gates.**
