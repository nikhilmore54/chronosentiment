# RUST CONSOLIDATION CONTRACT v1

## 1. Architectural Inflection Point
The laboratory has successfully completed its rapid Python-based exploratory metrology phase. However, continuing to build canonical physics and observatory logic in Python risks converting the system into "a Python research shell wrapped around a Rust replay core." This breaks the single-source-of-truth guarantee and weakens replay equivalence. 

## 2. The Freeze Mandate (Phase 1)
Effective immediately, Python expansion is frozen. Python will NO LONGER be used to define:
- Canonical topology injection
- Core morphology math (Occupancy, Autocorrelation, Entropy)
- Strategy cognition geometry simulation
- Admissibility evaluation

Python's scope is strictly downgraded to:
- Visualization (Deformation phase portraits)
- Sweeping runner wrappers (dispatching Rust binaries)
- Offline data wrangling

## 3. The Porting Mandate (Phase 2)
The stable concepts discovered during the Python exploratory phase will be canonicalized into the Rust core. The target module structure inside `chronosentiment-core/` is:
- `core/src/topology.rs`: Owns `plateau_low`, `impulse_shock`, `drift_field`, `fragmented_regime`, `osc_P_A`.
- `core/src/cognition.rs`: Owns orthogonal memory structures (`rolling_bounded`, `event_reset`, `accumulator`).
- `core/src/morphology.rs`: Owns type-safe, deterministic computation of `Occupancy`, `TransitionEntropy`, and `Autocorrelation(L=1)`.

## 4. Single Source of Truth
By moving these mechanics into Rust, we regain type safety, deterministic ownership, and absolute replay reproducibility. The laboratory's execution climatology observability will be permanently anchored to the strict compilation guarantees of the Rust environment, preventing silent semantic drift.
