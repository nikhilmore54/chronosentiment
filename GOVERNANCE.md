# ChronoSentiment Governance & Freeze Policy

ChronoSentiment has reached operational maturity. To protect the integrity of the project and prevent it from reverting into a conceptual research environment, the following strict boundaries are permanently enforced.

## The Three Freezes

| Freeze | Definition | Enforcement |
| :--- | :--- | :--- |
| **Engine Freeze** | No new replay subsystems. No distributed orchestration fleets, GPU accelerators, or continuous live-streaming runners. | The execution engine remains mechanically simple and horizontally constrained. |
| **Invariant Freeze** | No new certification theories or abstract topologies. | The certification surface is locked to explicit chronological equivalence, sequence integrity, and deterministic trace boundaries. |
| **Narrative Freeze** | The `README.md` and public facing documentation must remain strictly operational. | No philosophy, no ecology terminology, no taxonomy debates. The documentation only answers what the tool does, how to install it, and how to operate it. |

## Operational Scope Constraint

ChronoSentiment is designed for deterministic replay, verification, and divergence isolation workflows.

It is not:
- a live trading engine,
- an autonomous execution agent,
- a generalized observability platform,
- or a distributed stream-processing framework.

Future development must preserve the project's bounded operational scope.

## Allowed Contributions
Future development is strictly limited to:
* **Usability & Ergonomics:** Making the CLI output clearer, safer, and more mechanically explicit.
* **Documentation & Examples:** Enhancing onboarding workflows for external infrastructure engineers.
* **Installation & Packaging:** Improving cross-platform compilation or binary distribution.
* **Operational Cleanup:** Ensuring strict environment hygiene (e.g. enhancements to `chrono clean`).

## Core Product Identity
ChronoSentiment is **not** a generalized debugging intelligence, nor is it a massively scalable distributed replay platform. 

It is a specialized tool for **reproducible execution divergence isolation**.

Any pull request or architectural proposal that violates this identity will be rejected.
